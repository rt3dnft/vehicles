# 3D Interactive NFT Assets

This repository contains a collection of **3D GLB models** created for an interactive **3D NFT project**.

The collection includes detailed 3D assets such as:

* ✈️ **Aircraft**
* 🚗 **Cars and vehicles**
* 🏠 **Houses and architectural models**
* 🌐 **Other 3D objects and environments**

These models are designed to be integrated into an interactive web experience, allowing users to **explore and interact with each asset directly**.

Users can rotate, inspect, and view the 3D models from different angles using their **computer mouse** or, on mobile devices, through **touch gestures with their fingers**.

The goal of the project is to combine **3D modeling, interactive web technology, and NFTs** to create an immersive digital experience where each asset can be explored rather than simply viewed as a static image.

### Technologies

* **GLB / glTF** — 3D model format
* **Web-based 3D rendering**
* **Interactive mouse and touch controls**
* **NFT integration**
